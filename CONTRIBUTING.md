# Mitwirken

Bitte einen Fehler mit App-Version, HA-Version, Architektur und reproduzierbaren Schritten beschreiben. Keine Zugangsdaten oder privaten Konfigurationen veröffentlichen.

Vor einer Änderung `npm run check` und die Python-Tests ausführen. Änderungen am App-Transport benötigen Tests für unberechtigte Anfragen und fehlerhafte Werte. Änderungen an Animationen und Layout bitte mobil und breit in beiden Farbmodi prüfen.

Die UI-Quellen liegen unter `src/`. `npm run build:app` erzeugt die App-Karte einschließlich der zusätzlichen Steuerungen. Erzeugte Dateien ebenfalls einchecken. Physische Heizungsänderungen sind kein automatischer Testschritt.
